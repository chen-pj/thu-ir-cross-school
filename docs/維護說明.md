# 維護說明

給負責更新儀表板的人看。一般使用者請看 [README](../README.md)。

## 檔案在哪裡

| 路徑 | 內容 |
| --- | --- |
| `data/dashboard.json` | 各指標、學制、年度的比較結果（含口徑摘要） |
| `data/notes.json` | 卡片分組與各指標說明文字 |
| `src/index.html` | 頁面範本（樣式與程式，不連外部資源） |
| `src/fonts/` | 嵌入頁面的思源黑體子集 |
| `tools/config.py` | 口徑設定：報表清單、欄名、學制、指標區塊、排名參數 |
| `tools/fetch.py` | 下載平台報表到 `data/raw/<年>/`（不進版控） |
| `tools/compute.py` | 把 `data/raw/<年>/` 算成 `data/dashboard.json` |
| `tools/subset_font.py` | 產生字型子集 |
| `tools/build.py` | 組出 `dist/index.html` |
| `.github/workflows/pages.yml` | 推送到 `main` 後自動建置並發布到 GitHub Pages |

## 每年更新

教育部平台每年公布新學年度資料後執行一次。順序是：下載 → 計算 → 建置 → 人工檢查 → 推送。

```bash
python tools/fetch.py --folder 115     # 1. 下載報表
python tools/compute.py                # 2. 計算名次，產生 data/dashboard.json
python tools/build.py                  # 3. 組出網頁並驗證
python -m http.server -d dist 8000     # 4. 在 http://localhost:8000 檢查畫面
```

檢查沒問題後 commit 並推送到 `main`，網站會自動更新（約 1～2 分鐘）。推送前請再確認一次，推上去就是公開的。

### 各步驟注意事項

**下載（fetch.py）**
- `--folder` 是平台網址 `.../static_file/<編號>/` 的資料夾編號，每年要到平台確認（114 學年度為 `114`）。
- 下載前先列出檔案清單，經負責人同意再下載。
- 檔名必須和平台完全一致。平台改檔名時會出現 HTTP 404，請修改 `tools/config.py` 裡該報表的 `name`。
- `fetch.py` 尚未實際連線測試過，第一次使用請留意輸出，必要時手動下載報表放進 `data/raw/<年>/`。

**計算（compute.py）**
- 預設讀 `data/raw/` 底下最新的年度資料夾；資料更新日期預設為今天，可用 `--date YYYYMMDD` 指定。
- 內建檢查：欄名對應、缺值字串、東海每年都在母體、比較結果可追溯到完整排名、東海數值直接回查原始 CSV。任一項不通過就會中止。
- 系所報表驗算不一致只會提醒，交付前要查明原因。
- `python tools/compute.py --check` 只比對不寫檔，可確認重算結果與現有 `data/dashboard.json` 是否相同。
- 口徑（`tools/config.py` 的報表、區塊、學制、代碼對照）要改之前，先經負責人確認。

**建置（build.py）**
- 只把頁面用得到的欄位放進網頁，內部區塊編號（B01～B17）換成中性代號。
- 逐值比對網頁與 `data/`，有任何數值不同就中止；網頁若含內部編號或外部資源請求也會中止。
- 若提醒「字型缺字」，執行 `python tools/subset_font.py` 重新產生字型（需要 `pip install fonttools`），再重新建置。

## 環境需求

- Python 3（GitHub 自動建置使用 3.12）
- `compute.py` 需要 pandas、numpy；`subset_font.py` 需要 fonttools
- macOS／Linux 請把指令中的 `python` 改成 `python3`

## 規則

- 只放教育部公開平台的資料，校內資料不得放入本儲存庫。
- GitHub Pages 網站一律公開，即使儲存庫設為私人也一樣。
- `data/raw/` 不進版控，原始報表只存在下載者的電腦。
- 口徑以 `tools/config.py` 與 `data/dashboard.json` 的「口徑摘要」為準。
